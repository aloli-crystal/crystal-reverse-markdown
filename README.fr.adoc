= reverse-markdown
:source-language: crystal

Convertit du HTML en Markdown. Portage Crystal du gem Ruby https://rubygems.org/gems/reverse_markdown[reverse_markdown] (v3.0.2).

== Installation

Ajouter dans votre `shard.yml` :

[source,yaml]
----
dependencies:
  reverse-markdown:
    github: aloli-crystal/reverse-markdown
    version: "~> 3.0.2.4"
----

== Utilisation

=== Bibliothèque

[source]
----
require "reverse_markdown"

html = "<h1>Bonjour</h1><p>Un paragraphe en <strong>gras</strong>.</p>"
markdown = ReverseMarkdown.convert(html)
puts markdown
# => # Bonjour
#
# Un paragraphe en **gras**.
----

==== Options

[source]
----
# Balises inconnues : :pass_through (par défaut), :drop, :raise
ReverseMarkdown.convert(html, unknown_tags: :drop)
----

=== CLI

[source,bash]
----
# Compiler le CLI
crystal build bin/reverse-markdown.cr -o bin/reverse-markdown

# Convertir un fichier
reverse-markdown input.html

# Écrire dans un fichier
reverse-markdown input.html -o output.md

# Depuis stdin
curl https://example.com | reverse-markdown

# Options
reverse-markdown --unknown-tags drop input.html
----

== Éléments supportés

[cols="1,1"]
|===
| HTML | Markdown

| `<h1>` à `<h6>` | `#` à `######`
| `<p>` | paragraphe
| `<strong>`, `<b>` | `**gras**`
| `<em>`, `<i>` | `*italique*`
| `<del>`, `<s>` | `~~barré~~`
| `<code>` | `` `code en ligne` ``
| `<pre><code>` | bloc de code
| `<a>` | `[texte](url)`
| `<img>` | `![alt](src)`
| `<ul>/<li>` | `- élément`
| `<ol>/<li>` | `1. élément`
| `<blockquote>` | `> citation`
| `<table>` | tableau en pipes
| `<hr>` | `---`
| `<br>` | saut de ligne
| `<sup>` | `<sup>texte</sup>` (passthrough)
|===
